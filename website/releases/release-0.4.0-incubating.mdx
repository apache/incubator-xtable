## [Release 0.4.0-incubating](https://github.com/apache/incubator-xtable/releases/tag/0.4.0-incubating) ([docs](https://xtable.apache.org/docs/how-to))
This is the fourth official Apache release for Apache XTable (Incubating), an incubating project under the Apache Software Foundation.
Apache XTable™ (Incubating) facilitates omni-directional interoperability across data processing systems and query engines by allowing users to convert between open table formats without the need to rewrite any data files.
Currently, Apache XTable™ (Incubating) supports the open-source table formats for Apache Hudi, Apache Iceberg, and Delta Lake, and reads Apache Paimon and Apache Parquet as sources.

## ✨ What's Changed
### 🔄 Core Functionality Enhancements

#### New formats:
* Added a **Delta Kernel** conversion target.
* Added **Apache Paimon source** support, with incremental sync and column stats.
* Added **Apache Parquet source** support, with partition extraction and incremental sync.

#### Table Format Sync Improvements:
* Delta source: extract **nested field statistics**.
* **Nested-column partition** support in `HudiPartitionValuesExtractor` with hive-style partitioning.
* Fall back to **parquet footers** when metadata-table column stats are missing.
* Enable **Delta checkpoint CRC** exception throwing by default.
* Add additional properties when converting for **Hudi**.

#### Bug fixes:
* Delta: null partition value for composite generated-column partitions, map-key path handling, NPE for binary in map/array schemas, and column-mapping-enabled source tables.
* Hudi: batch `INSERT_OVERWRITE` replacecommits dropping adds, and empty `EarliestCommitToRetain`.
* Iceberg: nested comments with qualified name, schema sync, and empty source table.
* Parquet: snapshot sync on multiple commits with partitions, and schema-conversion bugs.

### 📦 Packaging & Distribution
* Added **xtable-spark-runtime**, a thin drop-in Spark bundle for Spark 3.4 and 3.5.
  It is published as `org.apache.xtable:xtable-spark-runtime_2.12:0.4.0-incubating`.
  See [Run XTable on Apache Spark](https://xtable.apache.org/docs/spark-runtime).
* Made the bundled **xtable-utilities** jar runnable again.
* Fixed the scope of spark-catalyst in the utilities bundle.

### 🧪 Testing & Quality
* Added an initial integration test for the **XTable REST service**.
* Improved `TestHudiInstantUtils` with parameterization and more cases.
* Removed wildcard imports and enforced with **Spotless**.
* Removed redundant `getSnapshotAt` calls per commit.

### 📘 Documentation & Community
* Added a **0.3.0 release page** and updated the **community sync** page.

### 🧰 Infrastructure & Maintenance
* Upgraded **Apache Iceberg** to 1.9.2 and **Avro** to 1.12.0.
* Added a **Maven wrapper** for consistent builds.
* Automated **license file generation and validation**.
* Restored the **delombok** execution so release builds generate javadoc jars.
* Added a **Source Build Check** workflow that builds the source release without any installed XTable artifacts.
